    Verification¶

    This chapter describes how the model is checked and how to run the checks. The final full run gave 433 PASS, 0 FAIL, 0 SKIP with both backends, on Windows 10 with Scilab 2027.0.0, the default stage file and Stepper-C at commit 3ef0f7e.

    How the model is checked¶

    Check Against Tests
    Motor and control behavior Theory: time constants, power balance, ripple, spin-down T00 to T13, B01
    Scilab model Python twin, written separately, with reference data in tests/reference/ X01 to X04
    C library in Xcos Scilab prototype, sample by sample S01 to S06
    Lab diagrams and report The specified limits, labels and scenarios S07 to S11
    MIL SIL M01
    Window and settings The specified order and messages C01 to C03

    Running the tests¶

    WScilex-cli -quit -f tests/run_all.sce      # Windows
scilab-cli -quit -f tests/run_all.sce       # Linux

    The exit status is 1 when a test fails. The log starts and ends with the library folder and the stage file in use. A full run took 386 minutes.

    Task How
    Run a group from the window Group All, SIL, MIL or Model, then Run tests and Refresh
    Run selected tests Set SSTEP_TEST_FILTER, a regular expression over the file names; see below
    Run the second backend run_all.sce starts it by itself, through tests/run_sil_backend.sce

    For example, to run C01 and T13:

    SSTEP_TEST_FILTER="C01|T13" scilab-cli -quit -f tests/run_all.sce

    In PowerShell, first set $env:SSTEP_TEST_FILTER = "C01|T13". A filter that matches no file runs nothing and still reports 0 failure(s), so check that the log lists the tests you expected.

    Testing another stage file¶

    Select the file in the window, or set SSTEP_STAGE_FILE, and run the tests. Simulations and tests use it, and the log names it.

    • A file that is not valid counts as a failure, and the tests do not fall back to the default silently.
    • Test X04 computes its reference with the Python twin for the active file, which needs SSTEP_PYTHON or a Python in PATH with numpy and scipy. Otherwise it reports SKIP.
    • Tests that compare against numbers from the default stage can fail with a stage of other values. For example, S05 fails when dead time and diode voltage change while the leg error table stays the same, because the averaged and the switching model then describe different stages. Decide whether a failure comes from the new stage values before treating it as a defect.

    Selected tests (C0|X04|T10|S01) ran on another stage file. A full run was made only on the default one.

    Python twin¶

    tools/ holds a separate implementation of parts of the model, in Python with numpy and scipy. It has no stall detector, so the X tests run with detection off.

    python tools/ref_model.py                # motor tests
python tools/ref_ctrl.py                 # current loop tests
python tools/ref_motion.py               # motion tests
python tools/ref_switching.py            # switching stage tests
python tools/ref_ext.py                  # T08, T11, T12

    Add --write to the first four to regenerate tests/reference/*.csv. With another stage, ref_switching.py --stage <file> --out <file> writes the reference elsewhere.

    Known gaps¶

    • Everything above is simulation. The model has not been validated against a measured motor in this manual, and several motor parameters are derived or assumed.
    • All results come from Windows. The Linux path of sil_build() was not run for this manual.
    • M01 does not cover sine inputs or the table mode in MIL.
    • The look of the window and the diagrams has no automatic test.
